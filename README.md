# Zida Yang · 杨子达

Bilingual academic website for Zida Yang, a doctoral student at Guanghua School of Management, Peking University.

- [English homepage](https://yzd2002.github.io/)
- [中文主页](https://yzd2002.github.io/zh/)
- [Research index](https://yzd2002.github.io/publications.html)

## Editing the site

Edit publication and repository entries in `tools/content.py`. Update bilingual page copy and the original diagrams in `tools/build.py`. Run `python tools/build.py` and commit the generated pages and illustrations. Preview from the repository root with `python -m http.server`.

GitHub Pages serves the committed HTML from the root of the main branch. The site works without third-party fonts, analytics, or a runtime API key.
